# AJO Product Release Session

Explore the latest updates in Adobe Journey Optimizer (AJO) that empower businesses to deliver personalized, efficient, and impactful customer experiences. This session focuses on newly released capabilities designed to achieve personalization goals, optimize operations, and enhance team productivity.

>[!VIDEO](https://video.tv.adobe.com/v/3491221/?learn=on&enablevpops)

## Key takeaways

- **Standout features:** Learn what makes AJO a leader in customer journey orchestration.
- **New capabilities:** Explore features like dataset lookup, content decisioning, and journey path optimization.
- **Channel innovations:** Understand emerging channels like WhatsApp, web push, and iOS live activity.
- **Productivity enhancements:** Discover tools to streamline content creation and accelerate delivery processes.

These updates help businesses leverage advanced decisioning, experiment effectively, and reach customers across multiple channels, driving more conversions and improving operational efficiency.
