# Jumpstart your integration: getting started with campaign REST APIs

Campaign REST APIs offer a streamlined way to create valuable customer interactions by bridging moments of engagement with marketing or service actions. This session is part of the Ultimate Success series and is designed to help you understand and utilize these APIs effectively.

## Key takeaways

- Learn how to translate a use case into a small, testable integration story.
- Understand where APIs create value and where they might not be the right tool.
- Gain insights into crafting request shapes, setting guardrails, and establishing paths to production.

## Overview

Adobe Campaign REST APIs are not just tools; they are a gateway to creating immediate and personalized customer interactions. These APIs allow you to:

- Trigger specific actions based on customer moments, such as sending confirmation emails or updating user preferences.
- Enable seamless integration with other applications, including Adobe and external systems.
- Support low-latency, event-driven use cases, such as abandoned cart notifications, welcome emails, and transactional confirmations.
