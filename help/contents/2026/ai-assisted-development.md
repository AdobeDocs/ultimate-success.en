# AEM Agent Skills: AI-Assisted Development Done Right

Learn how Adobe's open-source AEM Agent Skills empower coding assistants with Adobe-vetted context, enabling them to produce consistent and production-ready AEM code.

>[!VIDEO](https://video.tv.adobe.com/v/3502967/?learn=on&enablevpops)

## What You Will Learn

- Understand the importance of providing the right AEM context to AI coding assistants.
- Explore how Agent Skills ground tools like Cursor, Copilot, and Claude Code.
- Learn techniques to improve coding consistency and production readiness from the first prompt.

## Target Audience

This session is ideal for:

- Developers looking to streamline their AEM projects.
- Project leaders aiming to enhance production workflows.
- Users at beginner, intermediate, or advanced levels seeking to adopt AI-assisted development practices.

## Agenda

1. **Introduction**
   - Overview of AEM Agent Skills.
   - The need for contextual AI in development.

1. **Exploring Agent Skills**
   - Defining and understanding agent skills.
   - The role of agent skills in reducing AI drift.
   - Open-source contributions and community involvement.

1. **Key Features of AEM Agent Skills**
   - Create Component Skill: Simplifying component creation.
   - Dispatcher Skill: Enhancing configurations for performance and security.
   - Code Assessment Skill: Maintaining alignment with AEM best practices.

1. **Live Demonstrations**
   - Practical examples of using AEM Agent Skills.
   - Interactive walkthroughs of creating components, managing dispatchers, and assessing code quality.

1. **Q&A Session**
   - Addressing audience queries and providing additional resources.

## Resources and Next Steps

- Access the Adobe AEM Skills repository on GitHub for open-source contributions and examples.
- Explore additional documentation and tutorials on Adobe Experience League.

Join us to revolutionize your AEM development process with the power of AI and Adobe's specialized agent skills.
