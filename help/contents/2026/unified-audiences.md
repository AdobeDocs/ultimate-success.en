# Unlocking Federated Audience Composition (FAC) in AEP: From Data Silos to Unified Audiences

Discover how Adobe Experience Platform's Federated Audience Composition (FAC) breaks down data silos to deliver unified, actionable audiences. FAC enables organizations to activate audiences directly from existing data sources without moving or duplicating data. This approach respects data governance and privacy while facilitating real-time customer engagement.

>[!VIDEO](https://video.tv.adobe.com/v/3486505/?learn=on&enablevpops)

This session explains the integration of enterprise data warehouses with Adobe Real-Time CDP and Adobe Journey Optimizer, showing how businesses can unify customer profiles and enrich audience segments. FAC supports audience creation, enrichment, and profile enhancement, enabling personalized experiences across channels.

Video content is embedded below, demonstrating step-by-step implementation of FAC, from database setup to audience activation. This session highlights practical applications, emphasizing business outcomes like improved customer experiences and streamlined data operations.
