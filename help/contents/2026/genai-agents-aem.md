# Meet Your New Coworkers: The GenAI Agents of Adobe Experience Manager

This session gives an overview of the new GenAI Agents in Adobe Experience Manager — what they are, how they can be used, and where they make daily work measurably easier. Through a tour of the agent lineup and a live walkthrough, attendees see how agents accelerate content creation, surface quality and brand issues, and orchestrate changes across sites, while AEM remains the trusted system of record. Attendees leave knowing which agent solves which problem and how to get started.

>[!VIDEO](https://video.tv.adobe.com/v/3495848/?learn=on&enablevpops)

## Key topics

* Agents are coworkers, not replacements. The agents accelerate and orchestrate the work, but you stay in control and AEM remains the system of record. They speed up content creation and surface issues; the human still makes the decisions.  
* Right agent for the right job. Each agent solves a distinct problem — the Brand Experience Agent for keeping content on-brand, the Content Advisor Agent for content guidance and recommendations, and the Governance Agent for policy, permissions, and safe publishing. Knowing which one fits which task is the practical core of the session.  
* Start small. The recommended adoption path is one agent, one workflow, real content — then expand as your team builds trust and sees results, rather than turning everything on at once.
