# CJA Shared Components: Setup Once, Use Everywhere

Customer Journey Analytics (CJA) often involves managing multiple data views, which can lead to fragmented metrics and dimensions. Shared metrics and dimensions in CJA offer a solution by centralizing these components, providing a single source of truth across data views.

>[!VIDEO](https://video.tv.adobe.com/v/3491222/?learn=on&enablevpops)

## Key benefits

* **Improved usability**: Manage common metrics and dimensions from one location.
* **Simplified maintenance**: Update shared components once, and changes apply everywhere.
* **Enhanced consistency**: Ensure all teams analyze data uniformly.

## Why it matters

Shared components reduce duplication, improve governance, and boost trust in data. Admins save time, analysts onboard faster, and organizations achieve better reporting alignment.

## How it works

Shared components are managed within a single connection. Admins can import, reconcile, and merge duplicate components, ensuring clean and consistent definitions. The intuitive interface supports both tactical and strategic governance approaches.

## Business outcomes

Organizations achieve scalable analytics, reliable data governance, and reduced manual work, ultimately aligning teams and improving decision-making.
